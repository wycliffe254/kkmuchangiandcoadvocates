# K.K. Muchangi & Co. Advocates website

Static site: HTML, CSS and a small JS file. No build step is needed to host it; upload the folder to any static host (Netlify, Cloudflare Pages, cPanel, etc.). Open index.html to view it locally.

## Edit content
Content is generated by `build.py` using files in `src/`. Edit the CONFIG block and text, then run `python3 build.py` (needs Pillow and numpy). Note: build.py writes to the OUT path set at the top; change it to suit your machine. Or edit the HTML files directly.

## Configure before launch
1. DOMAIN in build.py: enables canonical URLs, Open Graph URL, sitemap.xml and the robots.txt sitemap line.
2. FORM_ENDPOINT in build.py: e.g. a Formspree endpoint set to deliver to kkmuchangiadvocates24@gmail.com. Until set, the form says it is not connected and sends nothing.
3. Replace assets/img/kk-logo.png with the original high-resolution or vector logo when available.
